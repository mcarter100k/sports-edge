# Reviews

One file per review: `<YYYY-MM-DD>_<study>_<stage>.md`, where stage is
`prereg` or `result`. Each is the reviewer's output saved verbatim (see
`.claude/agents/auditor.md` for the checklist), under a header naming the
commit reviewed and how the review was run. Files here are never edited
after they are saved; a second review is a new file.
